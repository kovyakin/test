
# Тестовое задание

## Requirements
- Laravel 11+.
- PHP 8.2 +.

## Описание
This package is developed on Vue3
and is added to work with Laravel.


## Установка
```php
git clone https://github.com/kovyakin/test.git
```
открываем терминал в папке test
копируем .env.example и переименовываем в .env
выставляем в .env:
APP_LOCALE=ru
DB_DATABASE=ваша бд
DB_USERNAME=ваш логин
DB_PASSWORD=пароль

 в терминале
 ```php
npm i
```
 ```php
composer update --no-scripts 
```
 ```php
php artisan key:generate
```
 ```php
php artisan migrate
```

 ```php
php artisan serve
```
